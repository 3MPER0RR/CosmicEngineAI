## Cosmic Engine

Minimal AI orchestration runtime in C/C++ with pluggable backend architecture.

Overview

Cosmic Engine is a lightweight command-driven runtime that routes user inputs to different AI and system backends:

LLM (Groq free API)
Image generation backend (experimental / multi-provider)
HTTP test backend
Extensible command router (engine layer)

The system is designed as a modular execution core, not a monolithic application.
